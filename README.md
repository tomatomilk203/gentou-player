# Local Album Player

手元にある幻燈の音源ファイルを、ブラウザ内だけで再生するための非公式ローカルプレイヤーです。

音源ファイルは配布物に含めません。利用者が自分で所持している音源を、端末のファイル選択から読み込んで使います。選択されたファイルの中から幻燈の曲だけを判定し、見つかった曲だけを公式順に並べます。歌詞は表示しません。

## スマホで使う場合

1. GitHub Pages などで公開された `gentou-player.html` をスマホのブラウザで開く
2. `音源ファイルを選ぶ` を押す
3. スマホ内のファイルアプリから、所持している音源ファイルを複数選ぶ
4. 見つかった幻燈の曲だけが公式順で並ぶので、曲一覧から再生する

## プレイリスト切替

- 幻燈限定曲: 夏の肖像、雪国、パドドゥ、靴の花火、さよならモルテン、いさな
- 第二章: 第一夜〜第十夜
- インストだけ: 第二夜〜第十夜

第一夜はオンボーカル曲として扱い、インストだけのプレイリストからは外しています。

iPhone / Android のブラウザでは、フォルダ選択やバックグラウンド再生の挙動が端末やブラウザによって変わることがあります。うまくいかない場合は、フォルダではなく音源ファイルを複数選択してください。

## バックグラウンド再生

PWA manifest、Service Worker、Media Session API に対応しています。スマホでホーム画面に追加して起動すると、通常のブラウザタブよりロック画面の再生コントロールに出やすくなります。

ただし、バックグラウンド再生の可否はOSとブラウザ側の制限に左右されます。音源ファイルそのものは端末内のファイルを参照するだけで、サーバーへアップロードしません。

## 機内モードで使う場合

GitHub Pagesで一度オンライン表示すると、アプリ本体はService Workerでキャッシュされます。ホーム画面に追加しておくと、次回以降は機内モードでもアプリ画面を開ける可能性が高くなります。

音源は端末内のダウンロード済みファイルを読み込みます。ブラウザの仕様上、iPhone / Androidではアプリを開き直した後にファイル選択を求められる場合があります。Chrome系ブラウザなど対応環境では、`前回の場所を読む` から保存済みフォルダを再読込できます。

## PCで使う場合

このフォルダで `start-gentou-player.cmd` を起動すると、ローカルサーバーが立ち上がり、ブラウザでプレイヤーを開きます。

## 配布時の注意

- 音源ファイルを同梱しないでください。
- 歌詞、楽譜、ジャケット画像、公式アプリ画面の複製を同梱しないでください。
- シリアルコード、認証情報、ダウンロード済み音源を共有しないでください。
- 公式配布物や公式サービスであるように見える表現は避けてください。
- このプレイヤーは、利用者が正当に所持している音源を聴きやすくするための補助ツールです。
- JASRAC / NexTone などの許諾番号は、許諾を受けた本人・サービスに対して発行されるものです。公式サイト等に表示されている許諾番号を、この非公式プレイヤーの許諾番号として転載しないでください。
- This project is unofficial and is not affiliated with or endorsed by Yorushika, its management, label, JASRAC, or NexTone.

## GitHub Pages で公開する場合

リポジトリには `gentou-player.html`、`README.md`、`.gitignore`、`manifest.webmanifest`、`sw.js`、`icon.svg` などのアプリ本体だけを入れてください。音源ファイルは `.gitignore` で除外しています。

GitHub の `Settings` -> `Pages` から公開ブランチを選ぶと、HTMLだけの静的ページとして公開できます。
